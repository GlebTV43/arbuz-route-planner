# ARBUZ — консольный поиск маршрутов

Консольное приложение для поиска поездок между городами через API Яндекс Расписаний. Ответы API сохраняются в файловом кэше, а ввод городов поддерживает подсказки по похожим названиям.

Лабораторная работа №7 по C++ в ИТМО.

## Возможности

- Поиск прямых маршрутов и вариантов с пересадками на выбранную дату.
- Интерактивный выбор городов и отображение участков поездки.
- Файловое кэширование JSON-ответов с TTL, ограничением размера и очисткой устаревших записей.
- Нормализация ввода и поиск похожих городов по расстоянию Левенштейна.
- Обновление локального каталога городов из списка станций API командой update cities.

## Что изучено и применено

- Подключение внешних библиотек через CMake FetchContent.
- HTTP-запросы с CPR и разбор JSON с nlohmann/json.
- Обработка ошибок, исключения и `std::optional`.
- Работа с файловой системой, временем и кэшированием.
- Строковые алгоритмы, Unicode и модульные тесты GoogleTest.
- Разделение приложения, команд, каталога городов и моделей маршрутов.
- Абстрактный HTTP-клиент, внедрение зависимостей и тестирование без реальных сетевых запросов.

## Сборка

Требуются компилятор с поддержкой C++23 и CMake 3.12 или новее. Команды выполняются из корня репозитория. При первой настройке CMake загружает тестовые или сетевые зависимости, поэтому нужен интернет.

```sh
cmake -S . -B build
cmake --build build --parallel
```

В Visual Studio и других генераторах с несколькими конфигурациями добавьте `--config Debug` к команде сборки. Исполняемые файлы в таком случае могут находиться в подкаталоге `Debug`.

## Тесты

В проекте есть тесты GoogleTest.

```sh
cmake --build build --target unit_tests
ctest --test-dir build --output-on-failure
```

Для генераторов с несколькими конфигурациями используйте `--config Debug` при сборке и `-C Debug` при запуске CTest.

## Использование

Для запросов нужен собственный ключ API Яндекс Расписаний. В PowerShell перед запуском задайте его через переменную окружения:

```powershell
$env:YANDEX_API_KEY = "YOUR_YANDEX_API_KEY"
.\build\bin\labwork7.exe
```

Исходная конфигурация сетевых зависимостей ориентирована на Windows и Schannel. На других платформах может потребоваться настроить TLS-бэкенд CPR/cURL.
